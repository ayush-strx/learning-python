# 📐 Math Module

The **math** module is a built-in Python module used to perform **mathematical calculations**.

Before using it, import the module.

```python
import math
```

---

# 📖 Common Math Functions

## 1. `sqrt()`

### Definition

Returns the **square root** of a number.

### Syntax

```python
math.sqrt(number)
```

### Purpose

Find the square root of a number.

### Example

```python
import math

print(math.sqrt(25))
```

Output

```text
5.0
```

---

## 2. `pow()`

### Definition

Returns a number raised to the specified power.

### Syntax

```python
math.pow(base, exponent)
```

### Purpose

Calculate the power of a number.

### Example

```python
import math

print(math.pow(2, 3))
```

Output

```text
8.0
```

---

## 3. `factorial()`

### Definition

Returns the factorial of a positive integer.

### Syntax

```python
math.factorial(number)
```

### Purpose

Calculate the factorial of a number.

### Example

```python
import math

print(math.factorial(5))
```

Output

```text
120
```

---

## 4. `ceil()`

### Definition

Rounds a decimal number **up** to the nearest integer.

### Syntax

```python
math.ceil(number)
```

### Purpose

Round a decimal upward.

### Example

```python
import math

print(math.ceil(5.2))
```

Output

```text
6
```

---

## 5. `floor()`

### Definition

Rounds a decimal number **down** to the nearest integer.

### Syntax

```python
math.floor(number)
```

### Purpose

Round a decimal downward.

### Example

```python
import math

print(math.floor(5.9))
```

Output

```text
5
```

---

## 6. `pi`

### Definition

Returns the mathematical constant **π (Pi)**.

### Syntax

```python
math.pi
```

### Purpose

Use the value of Pi in mathematical calculations.

### Example

```python
import math

print(math.pi)
```

Output

```text
3.141592653589793
```

---

## 7. `e`

### Definition

Returns **Euler's number (e)**.

### Syntax

```python
math.e
```

### Purpose

Use Euler's constant in mathematical calculations.

### Example

```python
import math

print(math.e)
```

Output

```text
2.718281828459045
```

---

# 📊 Math Module Functions

| Function | Purpose |
|----------|---------|
| `sqrt()` | Find square root |
| `pow()` | Calculate power |
| `factorial()` | Find factorial |
| `ceil()` | Round decimal upward |
| `floor()` | Round decimal downward |
