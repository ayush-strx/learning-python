# 📦 Package Management (`pip`)

**pip** is a tool used to **install, update, manage, and uninstall external Python packages (libraries).**

> **PIP = Pip Installs Packages**

Unlike built-in modules (`math`, `random`, `datetime`, `os`), external libraries must be installed using `pip`.

---

# 📖 Common pip Commands

## 1. Install a Package

### Definition

Installs a new Python package.

### Syntax

```bash
pip install package_name
```

### Purpose

Download and install an external library.

### Example

```bash
pip install numpy
```

---

## 2. List Installed Packages

### Definition

Displays all installed Python packages.

### Syntax

```bash
pip list
```

### Purpose

View all installed libraries.

### Example

```bash
pip list
```

---

## 3. Update a Package

### Definition

Updates an installed package to the latest version.

### Syntax

```bash
pip install --upgrade package_name
```

### Purpose

Upgrade an existing library.

### Example

```bash
pip install --upgrade numpy
```

---

## 4. Uninstall a Package

### Definition

Removes an installed package.

### Syntax

```bash
pip uninstall package_name
```

### Purpose

Delete a library from the system.

### Example

```bash
pip uninstall numpy
```

---

# 📊 Common pip Commands

| Command | Purpose |
|---------|---------|
| `pip install package_name` | Install a package |
| `pip list` | Show all installed packages |
| `pip install --upgrade package_name` | Update a package |
| `pip uninstall package_name` | Remove a package |
