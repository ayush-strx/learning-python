# 🎲 Random Module

The **random** module is a built-in Python module used to generate **random numbers and random selections**.

Before using it, import the module.

```python
import random
```

---

# 📖 Common Random Functions

## 1. `randint()`

### Definition

Returns a **random integer** between the given range (**both values are included**).

### Syntax

```python
random.randint(start, end)
```

### Purpose

Generate a random integer within a specified range.

### Example

```python
import random

print(random.randint(1, 10))
```

Possible Output

```text
7
```

---

## 2. `choice()`

### Definition

Returns **one random element** from a sequence such as a list, tuple, or string.

### Syntax

```python
random.choice(sequence)
```

### Purpose

Select a random item from a sequence.

### Example

```python
import random

fruits = ["Apple", "Mango", "Banana"]

print(random.choice(fruits))
```

Possible Output

```text
Banana
```

---

## 3. `shuffle()`

### Definition

Randomly rearranges (shuffles) the elements of a list.

### Syntax

```python
random.shuffle(list)
```

### Purpose

Change the order of elements in a list randomly.

### Example

```python
import random

numbers = [1, 2, 3, 4, 5]

random.shuffle(numbers)

print(numbers)
```

Possible Output

```text
[4, 1, 5, 2, 3]
```

---

## 4. `random()`

### Definition

Returns a **random floating-point number** between **0.0 and 1.0**.

### Syntax

```python
random.random()
```

### Purpose

Generate a random decimal number.

### Example

```python
import random

print(random.random())
```

Possible Output

```text
0.583621
```

---

# 📊 Random Module Functions

| Function | Purpose |
|----------|---------|
| `randint(start, end)` | Generate a random integer in a given range |
| `choice(sequence)` | Select a random element from a sequence |
| `shuffle(list)` | Shuffle the elements of a list |
| `random()` | Generate a random decimal number between 0.0 and 1.0 |
